01 Open source

Merged into Ion Fusion

Four pull requests merged into fusion-java, the runtime of Ion Fusion, a programmable language for JSON and Amazon Ion data. They run from a serializer bug fix to a public API migration, each reviewed by the project's maintainers, including the co-creator of Amazon Ion.

  1. #580 Sep 2026 Public API MERGED

    Move ionization methods from FusionRuntime to TopLevel

    ionize and ionizeMaybe now live on TopLevel, implemented through the withEvaluator() helper from #521. The old methods were removed rather than deprecated once nothing outside the test suite called them, and a test helper that evaluated in one top level but ionized through another now uses the same one for both.

    Fixes #5159 files View PR #580
  2. #521 Apr 2026 Interpreter internals MERGED

    Centralize FusionInterrupt handling in the embedding layer

    Introduced an EvalTask<T> functional interface and a withEvaluator() helper, so translating a FusionInterrupt into a FusionInterruptedException happens in one place. Every call site in the embedding layer now goes through it, including ionize and ionizeMaybe, which had been missing the handling.

    Closes #517 View PR #521
  3. #518 Apr 2026 Public API MERGED

    Add ionize(Object, IonWriter) to TopLevel

    Exposed ionization on TopLevel, where a full evaluation context is available, writing Fusion values straight to an IonWriter without building an Ion DOM first. Interrupt handling matches the other StandardTopLevel methods, with Javadoc for the new public method.

    Closes #292 View PR #518
  4. #490 Apr 2026 Bug fix MERGED

    Fix write() quoting of symbols in proper sexps

    write was quoting operator symbols such as + inside s-expressions, because its manual path had no sexp context. Proper sexps now delegate to ionize() through a temporary IonWriter; improper ones keep Fusion's dotted-pair rendering.

    (write (quote (+ 1 2)))
- ('+' 1 2)
+ (+ 1 2)

Greek Hospital Management API

featured

REST API for patients, hospitalisations and medical tests, modelled on the Greek public healthcare system with a Greek-language MySQL schema. Stateless JWT authentication with role-based access control (DOCTOR / CLERK / ADMIN) enforced per HTTP method, strict controller → service → DAO layering on JdbcTemplate, and an atomic clerk workflow that registers and admits a patient in one @Transactional request. api-gateway

featured

Reverse-proxy gateway built with FastAPI, httpx and Redis. Per-IP, per-route rate limiting on a Redis sliding window (an atomic Lua script) with temporary bans, retries with exponential backoff, a circuit breaker (CLOSED → OPEN → HALF-OPEN), JWT auth and response caching, with all shared state in Redis so instances scale horizontally. An admin API exposes metrics, circuit states and limits, and a mock upstream injects failures for testing. Runs under Docker Compose or Kubernetes; CD shipped it to AWS through ECR to EC2, and that target is now defined in Terraform.

unix-process-management

Five child processes fan messages into one Unix pipe; the parent drains the read end until every writer has closed and read() returns EOF, then reaps each child with wait(). Written for the Distributed Systems course at UoWM, following Tanenbaum and Bos's Modern Operating Systems. A multi-stage Docker build removes the need for a local C toolchain and cuts the image by more than 70%.

tcp-prime-factors-server

TCP client and server in C. The server forks a child per connection and returns the prime factors of each integer the client sends, validating input with strtol and reaping children with waitpid(WNOHANG). Started as Distributed Systems coursework at UoWM; the multi-stage Docker build ships only the stripped binary.

05 Published

Research

A technical report on time-series preprocessing, deposited on Zenodo with a permanent DOI.

Segmentation and Sampling in Time-Series Data

● Published

Η Σημασία της Διαχείρισης Χρόνου και Χώρου: Segmentation και Δειγματοληψία σε Δεδομένα Χρονοσειρών

Zenodo · technical report · not peer reviewed

How sampling and windowing decisions bound the information available to every downstream algorithm. Covers the Nyquist–Shannon criterion and aliasing, resampling and interpolation for aligning sensors running at different rates, sliding-window versus event-based segmentation, label noise at window boundaries, and how overlapping windows leak data across the train/test split when the split happens after windowing instead of at source level. Written in Greek with an English abstract; eight references and six original figures generated in Python.
